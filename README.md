# SI／PI 養成之路：公開試閱版

這是一套給初學者閱讀的 SI／PI 白話試閱教材，從基本觀念一路介紹到高速介面、量測與系統級 sign-off。

## 內容

- 01～06：SI／PI 基礎、反射、PDN、傳輸線、串擾與差動訊號。
- 07～12：I/O Model、S 參數、平面／SSN、DDR4／DDR5、SerDes、IBIS-AMI、量測與 sign-off。
- 每篇章節都搭配教學示意圖與小練習。

## 章節

請直接開啟資料夾內的 `試閱_01`～`試閱_12` Markdown 文件。

## 說明

本 Repo 只包含公開試閱內容與示意圖，不包含原始教材、內部資料、來源檔案或私人資料索引。完整課程整理與原始資料維持在私人環境中。

## 插圖

圖片採用簡化的教學示意方式，重點是幫助讀者理解訊號路徑、回流、反射、串擾、差動與驗證流程；正式設計仍應以實際規格、模型與量測結果為準。
